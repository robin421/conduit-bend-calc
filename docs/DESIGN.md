# 产品设计：Conduit Bend Calc

## 1. 信息架构
底部 3 个 Tab：
- **计算**（首页）：4 种弯管计算器入口 + 最近一次计算快捷入口
- **速查表**：角度常数表 + 弯管器 take-up 表
- **历史**：计算记录列表

## 2. 页面详述

### 2.1 计算首页
- 顶部：WattFlow 品牌栏（`⚡` 电工橙 logo + "WattFlow" + "Conduit Bend Calc"），
  作为 native-stack 的 `headerTitle` 渲染在炭黑导航头内；旧的 "BendCalc" 标题已废弃
- 4 张大卡片（垂直排列，每张 ≥72pt 高）：
  - Offset Bend（偏移弯）— 图标：⌐
  - 90° Stub（直角弯）— 图标：∟
  - 3-Point Saddle（三点马鞍弯）— 图标：⋀⋀
  - 4-Point Saddle（四点马鞍弯）— 图标：⋀⋀⋀
- 每张卡片：左侧图标 + 名称 + 一句话说明，右侧 chevron
- 点击进入对应计算器页面

### 2.2 Offset 计算器页
- 输入区（白色卡片 `#F9FAFB`）：
  - 障碍高度输入框（英制分数输入组件，大字号 24pt）
  - 角度选择器（6 个大按钮横排：10° 15° 22.5° 30° 45° 60°，选中态电工橙底）
- 结果区（炭黑底 `#1A1A1A` 大卡片）：
  - "两标记间距"：40pt Semibold 白色数字 + 电工橙单位
  - "Shrink 回补"：24pt 白色数字
- 大按钮"清空"（次级）——计算为实时，无需"计算"按钮
- 空状态：未输入时结果区显示 "—"

### 2.3 Stub / Saddle 计算器页
- 同 2.2 结构，输入项按需调整：
  - Stub：目标高度 + 弯管器选择（下拉：1/2" / 3/4" / 1" EMT，显示对应 take-up）
  - Saddle：障碍高度 + 障碍宽度 + 角度
- Saddle 结果：分步显示 Mark 1 / Mark 2 / Mark 3（+Mark 4），每步配一句话说明

### 2.4 速查表页
- 分段控件：角度常数 | 弯管器 take-up
- 表格样式，大字号，斑马纹（白/`#F9FAFB` 交替）

### 2.5 历史页
- 列表：每条显示计算器类型 + 关键输入 + 结果 + 时间
- 点击一条 → 跳回对应计算器并填入参数
- 右上角"清空"（二次确认）

## 3. 核心用户流程
1. 打开 App → 计算首页
2. 点 "Offset Bend" → 输入 6" → 点 30° → 结果区实时显示 12" / shrink 1.5"
3. 返回首页 → 点"速查表"确认常数 → 完成

## 4. UI 规范
- 主色：炭黑 `#1A1A1A`（顶栏、结果卡、主按钮）
- 强调色：电工橙 `#FF6B00`（选中态、CTA、关键数字单位）
- 背景：`#FFFFFF`；卡片底：`#F8F9FA`
- 文字：主 `#1A1A1A`，次 `#6B7280`
- 成功绿 `#16A34A`，错误红 `#DC2626`
- 派生可读色（对比度用）：浅底小字 `accentText #C2410C`；深色底主色文字 `primaryText`（深色模式 `#EDEDED`）
- 字体：系统字体（SF Pro / Roboto），数字用 Semibold 600
- 结果数字：40pt；正文 16pt；次要 14pt
- 圆角：8pt；**无阴影、无渐变**
- 按钮最小高度 56pt；数字/选择按钮 ≥64pt
- 深色模式：背景 `#121212`，卡片 `#1E1E1E`，文字 `#EDEDED`，主色抬升为 `#2E2E2E`，橙略提亮 `#FF8533`

## 5. 空/加载/错误态
- 空状态：结果区显示 "—"，配灰色提示"输入参数查看结果"
- 错误态：输入非法时输入框红框 + 红字提示，不清空已输入
- 无加载态（本地计算即时完成）

## 6. WattFlow 品牌与信息层级（T64）

### 6.1 品牌 chrome（首页 + 4 个 SEO 工具页）
- **品牌栏**：`⚡`（电工橙 `#FF6B00` 圆角底 + 白字）+ **WattFlow** 字样 +
  产品名 **Conduit Bend Calc**。SEO 工具页作为内容渲染在页面顶部；首页作为
  炭黑导航头的 `headerTitle`。文案单一来源 `src/seo/brand.ts`。
- **计算器切换条**：品牌栏下方，横向可滑动（窄屏）/ 平铺换行（宽屏 ≥600pt）。
  条目 = 4 个交互式工具页（Offset / 4-Point Saddle / Shrink / 90° Stub）+
  `All calculators`（回首页）。当前页：橙色下划线 + 橙色文字；其余灰色。
  Web 端渲染真实 `<a href>` 可抓取；单位选择经全局 `unitStore` 跨页保留。
- **页脚**：`Built by WattFlow for field crews.`
- **title 后缀**：` | WattFlow`（`withBrandTitle`，幂等）。
- 约束：不改 URL 结构，切换条只收录已有 Web 路由，不造死链。

### 6.2 信息层级
| 层级 | 内容 | 视觉 |
|---|---|---|
| L1 | 输入 + 结果 | 同一个 `SeoWorkspace` 白色工作区；结果卡炭黑底 + **40pt** 白字，全页锚点 |
| L2 | 单位 / 角度或管径预设 / 最近历史 | 紧贴 L1，中等强调；去掉冗余文字标签 |
| L3 | 说明文字 / 倍数表 / take-up 表 | 结果下方，浅灰底 + 小号灰标题，**默认折叠** |
| L4 | FAQ | 灰色手风琴，14pt 灰字 |

### 6.3 首屏指标（390×844，Safari 可视 ~700pt）
- 品牌 chrome ≈ 132pt + 工作区 ≈ 506–554pt = **646–694pt**，一屏可见
  "输入 → 计算 → 结果"；L3/L4 永不进首屏。
- 每个屏文件的顶部注释记录该页的高度分解。
