# 产品设计：Conduit Bend Calc

## 1. 信息架构
底部 3 个 Tab：
- **计算**（首页）：4 种弯管计算器入口 + 最近一次计算快捷入口
- **速查表**：角度常数表 + 弯管器 take-up 表
- **历史**：计算记录列表

## 2. 页面详述

### 2.1 计算首页
- 顶部：App 标题 "BendCalc"，深蓝底 `#0F2B46`，白字
- 4 张大卡片（垂直排列，每张 ≥72pt 高）：
  - Offset Bend（偏移弯）— 图标：⌐
  - 90° Stub（直角弯）— 图标：∟
  - 3-Point Saddle（三点马鞍弯）— 图标：⋀⋀
  - 4-Point Saddle（四点马鞍弯）— 图标：⋀⋀⋀
- 每张卡片：左侧图标 + 名称 + 一句话说明，右侧 chevron
- 点击进入对应计算器页面

### 2.2 Offset 计算器页
- 输入区（白色卡片 `#F9FAFB`）：
  - 障碍高度输入框（英制分数输入组件，大字号 24pt）
  - 角度选择器（6 个大按钮横排：10° 15° 22.5° 30° 45° 60°，选中态金色底）
- 结果区（深蓝底 `#0F2B46` 大卡片）：
  - "两标记间距"：40pt Semibold 白色数字 + 金色单位
  - "Shrink 回补"：24pt 白色数字
- 大按钮"清空"（次级）——计算为实时，无需"计算"按钮
- 空状态：未输入时结果区显示 "—"

### 2.3 Stub / Saddle 计算器页
- 同 2.2 结构，输入项按需调整：
  - Stub：目标高度 + 弯管器选择（下拉：1/2" / 3/4" / 1" EMT，显示对应 take-up）
  - Saddle：障碍高度 + 障碍宽度 + 角度
- Saddle 结果：分步显示 Mark 1 / Mark 2 / Mark 3（+Mark 4），每步配一句话说明

### 2.4 速查表页
- 分段控件：角度常数 | 弯管器 take-up
- 表格样式，大字号，斑马纹（白/`#F9FAFB` 交替）

### 2.5 历史页
- 列表：每条显示计算器类型 + 关键输入 + 结果 + 时间
- 点击一条 → 跳回对应计算器并填入参数
- 右上角"清空"（二次确认）

## 3. 核心用户流程
1. 打开 App → 计算首页
2. 点 "Offset Bend" → 输入 6" → 点 30° → 结果区实时显示 12" / shrink 1.5"
3. 返回首页 → 点"速查表"确认常数 → 完成

## 4. UI 规范
- 主色：深蓝 `#0F2B46`（顶栏、结果卡、主按钮）
- 强调色：警示金 `#F4C317`（选中态、关键数字单位、CTA）
- 背景：`#FFFFFF`；卡片底：`#F9FAFB`
- 文字：主 `#1F2933`，次 `#6B7280`
- 成功绿 `#2F855A`，错误红 `#C53030`
- 字体：系统字体（SF Pro / Roboto），数字用 Semibold 600
- 结果数字：40pt；正文 16pt；次要 14pt
- 圆角：8pt；**无阴影、无渐变**
- 按钮最小高度 56pt；数字/选择按钮 ≥64pt
- 深色模式：背景 `#121212`，卡片 `#1E1E1E`，文字 `#EDEDED`，强调金略降饱和

## 5. 空/加载/错误态
- 空状态：结果区显示 "—"，配灰色提示"输入参数查看结果"
- 错误态：输入非法时输入框红框 + 红字提示，不清空已输入
- 无加载态（本地计算即时完成）
