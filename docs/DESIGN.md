# 产品设计：Conduit Bend Calc

## 1. 信息架构
底部 3 个 Tab：
- **计算**（首页）：继续上次计算 + 弯管 / 电气计算 / 我的弯管器三组入口
- **速查表**：角度常数表 + 弯管器 take-up 表
- **历史**：计算记录列表

## 2. 页面详述

### 2.1 计算首页
- 顶部：真实应用图标（`assets/icon.png`）+ "Conduit Bend Calc"，
  作为 native-stack 的 `headerTitle` 渲染在深蓝导航头内；旧的 "BendCalc" 标题已废弃
- 最近一次有效计算显示在顶部，点击恢复输入、单位和弯管器。首次使用不显示空卡片。
- 计算器按「Conduit bending / Electrical calculators / My bender」分组，大卡片垂直排列（每张 ≥72pt 高）：
  - Offset Bend（偏移弯）— 图标：⌐
  - 90° Stub（直角弯）— 图标：∟
  - 3-Point Saddle（三点马鞍弯）— 图标：⋀⋀
  - 4-Point Saddle（四点马鞍弯）— 图标：⋀⋀⋀
  - 弯管组另含 Rolling Offset 和 Kicked 90°；电气组含 Conduit Fill、Voltage Drop 和 Wire Size。
  - 我的弯管器只保留 Dial In My Bender 入口，进入后选择 Quick Check / Full Fingerprint。
- 每张卡片：左侧图标 + 名称 + 一句话说明，右侧 chevron
- 点击进入对应计算器页面

### 2.2 Offset 计算器页
- 输入区（白色卡片 `#F9FAFB`）：
  - 障碍高度输入框（英制分数输入组件，大字号 24pt）
  - 角度选择器（6 个大按钮横排：10° 15° 22.5° 30° 45° 60°，选中态图标黄底）
- 结果区（深蓝底 `#1A1A1A` 大卡片）：
  - "两标记间距"：40pt Semibold 白色数字 + 图标黄单位
  - "Shrink 回补"：24pt 白色数字
- 大按钮"清空"（次级）——计算为实时，无需"计算"按钮
- 空状态：未输入时结果区显示 "—"
- 输入后立即显示结果和风险提示；示意图放在结果之后、默认折叠，通过 Show bend diagram 展开。
- 先显示标记距离、测量起点和对齐基准，再显示校准推广。Stub 区分 arrow 和 hook front-edge，不统一写箭头。

### 2.3 Stub / Saddle 计算器页
- 同 2.2 结构，输入项按需调整：
  - Stub：目标高度 + 弯管器选择（下拉：1/2" / 3/4" / 1" EMT，显示对应 take-up）
  - Saddle：障碍高度 + 障碍宽度 + 角度
- Saddle 结果：分步显示 Mark 1 / Mark 2 / Mark 3（+Mark 4），每步配一句话说明

### 2.4 速查表页
- 分段控件：角度常数 | 弯管器 take-up
- 表格样式，大字号，斑马纹（白/`#F9FAFB` 交替）

### 2.5 历史页
- 列表：每条显示计算器类型 + 关键输入 + 结果 + 时间
- 点击一条 → 跳回对应计算器并填入参数
- 右上角"清空"（二次确认）

## 3. 核心用户流程
1. 打开 App → 计算首页
2. 点 "Offset Bend" → 输入 6" → 点 30° → 结果区实时显示 12" / shrink 1.5"
3. 返回首页 → 点"速查表"确认常数 → 完成

## 4. UI 规范
- 图标配色唯一来源：`src/brandPalette.ts`。主色深蓝 `#0F2B46`，强调色图标黄 `#F4C317`，与现有 icon.png 一致。
- 浅色：背景 `#F5F8FB`，卡片白色，主文字深蓝，次要文字 `#52677B`，描边 `#D9E2EB`。
- 深色：背景 `#091D30`，卡片 `#15334F`，主文字 `#F3F6FA`，次要文字 `#AEC0D1`，描边 `#2B4862`。
- 顶栏和结果区使用图标深蓝，白色文字；结果标签 `#BED0DF`，关键单位可用图标黄。
- 选中/强调控件使用图标黄底 + 深蓝字，正常及白色按压反馈下对比度达到 4.5:1。浅底小字和输入焦点使用深金 `#806000`，避免黄字在浅底不可读；深色模式使用图标黄。
- 保留 `rgba(255,255,255,0.04)` 白色按压反馈，不使用黑色涟漪。
- 系统字体；结果 40pt，标题 24pt，正文 16pt，次要 14pt；数字等宽。
- 圆角 8pt，无阴影、渐变或装饰动画；按钮至少 56pt，数字/输入选项至少 64pt。

## 5. 空/加载/错误态
- 空状态：结果区显示 "—"，配灰色提示"输入参数查看结果"
- 错误态：输入非法时输入框红框 + 红字提示，不清空已输入
- 不可行的弯形对免费用户同样明确提示停止弯制；Pro 提供进一步分析和替代方案。
- 无加载态（本地计算即时完成）

## 6. WattFlow 品牌与信息层级（T64）

### 6.1 品牌 chrome（首页 + 4 个 SEO 工具页）
- **应用栏**：`assets/icon.png` 真实图标 + **Conduit Bend Calc** 产品名；导航头为图标深蓝，文字为白色。页头不显示公司字标或闪电替代图形。
- **计算器切换条**：品牌栏下方，横向可滑动（窄屏）/ 平铺换行（宽屏 ≥600pt）。
  条目 = 4 个交互式工具页（Offset / 4-Point Saddle / Shrink / 90° Stub）+
  `All calculators`（回首页）。当前页：黄色下划线 + 深金文字；其余灰色。
  Web 端渲染真实 `<a href>` 可抓取；单位选择经全局 `unitStore` 跨页保留。
- **页脚**：`Built for field crews.`
- **title 后缀**：` | WattFlow`（`withBrandTitle`，幂等）。
- 约束：不改 URL 结构，切换条只收录已有 Web 路由，不造死链。

### 6.2 信息层级
| 层级 | 内容 | 视觉 |
|---|---|---|
| L1 | 输入 + 结果 | 同一个 `SeoWorkspace` 白色工作区；结果卡深蓝底 + **40pt** 白字，全页锚点 |
| L2 | 单位 / 角度或管径预设 / 最近历史 | 紧贴 L1，中等强调；去掉冗余文字标签 |
| L3 | 说明文字 / 倍数表 / take-up 表 | 结果下方，浅灰底 + 小号灰标题，**默认折叠** |
| L4 | FAQ | 灰色手风琴，14pt 灰字 |

### 6.3 首屏指标（390×844，Safari 可视 ~700pt）
- 品牌 chrome ≈ 132pt + 工作区 ≈ 506–554pt = **646–694pt**，一屏可见
  "输入 → 计算 → 结果"；L3/L4 永不进首屏。
- 每个屏文件的顶部注释记录该页的高度分解。

## 7. 评分与 Pro 流程（T80）

- 首页 My Bender 之前与 Reference 页尾提供中立评分入口；自动评分仅在成功使用后返回首页空闲时请求，不与付费流程叠加。
- Pro 页分为 My bender / Bend options / History & export，先展示明确标注的示例、免费与付费边界和折叠 FAQ。底部固定本地价格、一次性购买、恢复和退出入口。
- 待付款显示等待确认与查询状态，保留免费使用入口；取消为中立提示，失败可重试。成功/恢复页由用户点击继续原任务，不自动跳走。
- 沿用现有字号、橙色控制面与白字/白色按压反馈；不加阴影、渐变或装饰动画。详见 [验收记录](validation/t80/README.md)。

## 8. 工单反馈（T82）

首页与 Reference 页尾使用现有 Card / BigButton 展示 Send feedback。说明环境信息和公开工单边界；点击后打开系统浏览器的共享表单，失败可重试，不清空计算输入。沿用主题与白色按压反馈，不新增图标依赖或装饰。详见 [接入与验收](feedbackHub.md)。

## 9. 会员页精修（T84）

- 产品名保持 **Conduit Bend Calc**；会员页导航标题复用 PRODUCT_NAME，不将 WattFlow 或测试标记当作产品名。
- 首屏为 24pt 标题、三项权益（16pt 标题 / 14pt 说明）和明确价格；不使用三个大型场景按钮堆叠信息。
- 示例默认折叠，展开后用 56pt 触区的文字导航切换 Bender / Bend checks / History；FAQ 默认折叠。保持示例标记，不写入用户设置。
- 购买区只保留价格行、一个 56pt 主按钮及同排文字操作（恢复 / 暂不）。购买页隐藏计算器底部导航，离开时恢复。
- 小高度（<640pt）或放大字体（fontScale>1.2）时操作区随内容滚动；正常竖屏固定底部并保留安全区。内容和操作区共用 600pt 最大宽度。
- 沿用已有颜色、字号、圆角与白色按压反馈；不增加依赖、阴影、渐变、插画或装饰动画。

## 10. 应用身份与图标主题（T85）

首页、工具页和抽屉页头统一使用真实应用图标 + Conduit Bend Calc，不显示 WattFlow 字标或闪电替代图形。浅/深主题均以现有图标的深蓝/黄色为基础；底部选中导航、输入焦点、按钮和结果区同步使用主题令牌。产品名和原有路由保持不变。
