# T84：Conduit Bend Calc 会员页精修

## 实现

产品名保持 Conduit Bend Calc，会员页标题使用 PRODUCT_NAME。采用现有主题、24/16/14pt 字级及白色按压反馈，未增加依赖、阴影、渐变或装饰动画。

首屏只突出标题、三项权益及价格。示例默认折叠，展开后通过简短文字导航切换；FAQ 默认折叠。固定购买区改为价格行、一个主按钮和同排文字操作；正常竖屏的模拟截图中操作区约 173pt（此前约 270pt）。进入会员页隐藏底部计算器导航，退出恢复；小高度或大字体时操作区随内容滚动。

既有商店定价、一次性购买、待付款禁止重购、恢复、显式继续任务等逻辑未改动。恢复/暂不仍有最小 56pt 触区。成功页采用居中确认区，避免操作文字重复。

## 验证

- TypeScript 和 372 项项目测试通过。
- Expo Web 生产导出通过。
- 390×844 深浅色检查：首页权益与价格可见；待付款只显示查询状态和继续免费使用；加载、购买中、失败、取消、恢复、成功状态均检查渲染；成功继续操作在预览中保留原任务。
- 示例切换检查 Bend checks / History，能展示实际计算样例和最近 20 条说明；没有写入用户配置或发起付款。
- 实际 Web 导航：进入会员页时 tablist 高度为 0，点击 Not now 后恢复为 41pt。
- 568×320 小高度检查：购买按钮可滚动到视区内（top 192 / bottom 248），无横向溢出。
- 01/02/03/05 截图为共用实际展示组件的模拟状态，US$4.99 是明确标注的夹具价格；04 是实际 Web 应用页面。原生安装结果另附。
- 没有修改用户系统字体设置；大字体随页滚动策略已实现，不能将普通字号截图称为所有辅助功能设置均已实测。
